# Currency Converter Java

## Overview
**Currency Converter** is a Java application that allows users to convert amounts from one currency to another using up-to-date exchange rates. This project demonstrates Java programming skills, GUI or console interaction (depending on your implementation), and basic knowledge of currency conversion logic.

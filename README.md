# Currency Converter Java

## Overview
**Currency Converter** is a Java application that allows users to convert amounts from one currency to another. This project helps users quickly calculate currency conversions without needing to search online. It also demonstrates basic Java programming skills, including variables, conditionals, loops, and user input handling.  

This project can be run in **console mode** or optionally with a **GUI interface** depending on your implementation.

---

## Features
- Convert between multiple currencies (e.g., USD, EUR, INR, GBP, JPY).
- Easy-to-use console or GUI interface.
- Supports decimal amounts.
- Lightweight and fast application.
- Can be extended to use live exchange rates via API.
